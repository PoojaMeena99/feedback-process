# Feedback Process — Justuju User Guide

This guide is for every Justuju team member using the Feedback Process app. You can request feedback, give feedback, and review feedback received from other team members.

## Sign in and account access

1. Sign in with your registered email address and password.
2. If you do not have an account, select **Create account** and verify your email address.
3. If you forget your password, select **Forgot password?** A reset link will be sent to your registered email address.

## Understand the dashboard

- **Waiting for Me:** feedback requests that need your response.
- **Requests Sent:** feedback requests you created.
- **Received feedback:** feedback that has been submitted for you.

Use the dashboard to create a request or review your pending feedback work.

## Request feedback

1. Select **Request feedback**.
2. Choose a feedback type, such as Learning Feedback or Project Completion Feedback.
3. Select the person who will give feedback.
4. Optionally add a purpose and due date.
5. Select **Send Request**.

The selected team member will receive a notification.

## Create custom questions

Use a custom template when the built-in feedback types do not fit your need.

1. In the request panel, select **Custom**.
2. Enter a template name and your questions.
3. Select **Save custom template**.
4. Select the feedback giver and send the request.

The selected feedback giver will see those custom questions in their form.

## Give feedback

1. Open the request from the notification bell or **Feedback Requests**.
2. Select **Fill** or **Give feedback**.
3. Answer each question clearly and respectfully.
4. Select **Submit Feedback**.

The person receiving feedback will be notified after submission.

## Review and complete received feedback

1. Open submitted feedback from a notification or the Feedback Requests page.
2. Read the feedback and add an acknowledgement comment.
3. Select **Acknowledge**.
4. Select **Close** when there are no open questions or follow-up actions.

The completed request remains available in **Feedback History**.

## Ask a question about feedback

If you need clarification about a feedback answer:

1. Open the submitted feedback.
2. Send a message in **Questions about this feedback**.
3. The other person can reply in the same conversation.

The conversation is saved with the feedback request. Resolve open questions before closing the request.

## Anonymous feedback

When creating a request, select **Keep the feedback giver anonymous** if the giver's identity should be hidden after submission.

The feedback receiver will see **Anonymous** instead of the giver's name. The giver can still see their own request and identity.

## Manage requests

- **Edit due date:** change the deadline for a pending request.
- **Cancel:** cancel a request that is no longer needed.
- **Decline:** decline a request when you cannot provide feedback.
- **Search and filters:** find requests by person, type, purpose, or status.

Completed, cancelled, and declined requests are available in **Feedback History**.

## Notifications

Use the bell icon to view new requests, submitted feedback, replies, and reminders. Selecting a notification opens the relevant request.

## Tips for useful feedback

- Use specific examples.
- Focus on work and behaviour, not the person.
- Suggest a practical next step for improvement.
- Keep the tone respectful and constructive.

## Report an issue

When reporting a problem, include:

```text
Feature: Request / Custom template / Login etc.
Expected: What should have happened
Actual: What happened instead
Screenshot: Attached
```
